# Arcaea PTT Tracker (潛力值追蹤器)

一個為音樂遊戲 《Arcaea》 玩家打造的現代化潛力值 (PTT) 追蹤與最佳 30 首成績 (Best 30, B30) 分析工具。支援電腦與行動裝置響應式排版，並內建快捷輸入鍵盤與行內 PTT 預估功能。

---

## 📖 核心概念與計算規則

1. **單曲 PTT (Play PTT)**：
   * 依據單曲的**譜面定數 (Constant)** 與**遊玩分數 (Score)** 自動計算。
   * 計算公式：
     * 分數 $\ge 10,000,000$ (PM)：定數 $+ 2.0$
     * 分數 $\ge 9,800,000$ (EX及以上)：定數 $+ 1.0 + \frac{\text{分數} - 9,800,000}{200,000}$
     * 分數 $< 9,800,000$ (EX以下)：定數 $+ \frac{\text{分數} - 9,500,000}{300,000}$（若計算結果為負，則單曲 PTT 計為 0）
2. **Best 30 (B30)**：
   * 取玩家所有歷史紀錄中，**單曲 PTT 最高的前 30 筆數據**之算術平均值。

## 🛠️ 功能使用教學

### 1. 新增與編輯紀錄 (Add & Edit Records)
* **新增紀錄**：
  * 電腦版：點擊頂部導覽列的「新增紀錄」按鈕。
  * 手機版：點擊畫面右下角的藍色浮動按鈕 (FAB)。
* **輸入分數**：
  * 系統支援**快捷分數數字鍵盤**（可在設定中開啟「手機快捷分數鍵盤」）：
    * 提供快速補零按鈕（如萬、十萬位數），方便快速輸入 Arcaea 的七位數成績。
    * 提供常用分數判定點快速鍵（如 `980k` = 9,800,000 (EX), `990k` = 9,900,000 (EX+), `10M` = 10,000,000 (PM)）。
* **自動更新 (autoUpdate)**：
  * 勾選自動更新後，當您匯入或更新時，系統將會優先處理此曲目。

### 2. 手機版手勢操作快捷鍵 (Mobile Gestures)
在手機版列表的卡片上，您可以利用以下手勢快速操作：
* **長按已啟用「自動更新」的卡片**：直接在瀏覽器新分頁中開啟 YouTube 搜尋該歌曲的 gameplay 影片（方便觀摩譜面）。
* **長按一般卡片**：自動彈出底部動作選單 (Action Menu)，可快速進行編輯、刪除或定位。
* **智慧防呆**：當您展開另一張卡片時，原先開啟的動作選單會自動收合，維持畫面整潔。

### 3. 行內 PTT 預估折線圖 (PTT Estimation)
展開手機版卡片後，您會看到一張微型的預估折線圖：
* **目前成績標記**：圖表上以**亮紅色圓點**標記您目前的成績與單曲 PTT。
* **分數預估滑動**：用手指在折線圖上滑動，系統會以**藍色指示線**預覽在該得分點時可獲得的 PTT。
* **自動歸位**：手指離開圖表後，數值將自動歸位，顯示目前的實際成绩。

### 4. Best 30 圖表與統計數據分析
* **圖表控制**：
  * 您可以在 B30 圖表的圖例 (Legend) 上點擊，動態顯示/隱藏「單曲 PTT 趨勢線」、「平均值參考線」或「中位數參考線」。
* **詳細數據檢視**：
  * **電腦版**：點擊圖表左上方標題列的「點擊此處查看詳細統計數據」，將會以 Dialog 呈現平均值、中位數、標準差及分數區間。
  * **手機版**：為了保證單手操作的舒適度，詳細統計數據會直接以單一欄位的卡片形式，直觀地排列在圖表正下方。

### 5. 管理員後台 (Admin Panel)
* 進入路徑：`/admin` (或於開發環境訪問 `admin.html`)。
* 功用：可選取資料庫中的不同玩家，即時同步並展示該玩家的 B30 分析圖表、完整成績列表及 PTT 潛力值細節，便於進行多玩家的數據管理與對比。

## 💻 本地開發與部署說明

### 系統環境要求
* [Node.js](https://nodejs.org/) (建議 v18 以上)
* [pnpm](https://pnpm.io/) (封包管理器)

### 1. 安裝依賴項目
於專案根目錄下執行：
```bash
pnpm install
```

### 2. 啟動開發伺服器
* 啟動前端開發伺服器（預設為 `http://localhost:5173/ArcaeaPTTTracker/`）：
  ```bash
  pnpm run dev:frontend
  ```
* 啟動後台管理 API 伺服器（預設為 `http://localhost:3000`）：
  ```bash
  pnpm run dev:server
  ```

### 3. 編譯與部署
* **編譯專案**：
  ```bash
  pnpm run build:frontend
  ```
* **部署至 GitHub Pages**：
  ```bash
  pnpm run deploy:frontend
  ```
